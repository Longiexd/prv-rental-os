# Workspace navigation

Rentals, Fleet and Management are labeled groups in the same sidebar. Modules remain on existing routes. The logo leads to the rental overview. All enabled modules remain reachable without switching a top bar; desktop logo and main header share a 70px baseline. Mobile presents enabled modules in the existing scrollable navigation. Quick booking actions are contextual to rental pages.

Per-company module visibility is driven by backend-confirmed entitlements. Direct API calls to disabled Fleet care and Analytics endpoints are rejected. See PLANS.md for private owner controls and plan behavior.
